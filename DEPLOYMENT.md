Clone the Repository\n\n```bash\ngit clone <repository-url>\ncd greennewstracker\n```\n\n### 2. Configure Environment Variables\n\nCopy the example environment file:\n\n```bash\ncp .env.example .env\n```\n\nEdit `.env` with your configuration:\n\n```env\n# Application\nNODE_ENV=production\n\n# OpenAI Configuration\nOPENAI_API_KEY=your_openai_api_key_here\n\n# Database\nDB_PATH=/app/data/greennews.db\nDOCKER_DB_VOLUME_PATH=./data\n\n# API Configuration\nAPI_PORT=3000\nAPI_HOST=0.0.0.0\nCORS_ORIGIN=https://yourdomain.com\n\n# Rate Limiting\nRATE_LIMIT_WINDOW_MS=900000\nRATE_LIMIT_MAX_REQUESTS=100\n\n# Worker Configuration\nWORKER_CRON_SCHEDULE=*/15 * * * *\nWORKER_FETCH_TIMEOUT=30000\nRSS_FETCH_INTERVAL_MINUTES=15\nRSS_MAX_ARTICLES_PER_FEED=50\n\n# Logging\nLOG_LEVEL=info\nLOG_FORMAT=json\n\n# Nginx Configuration\nNGINX_PORT=80\nNGINX_SSL_PORT=443\n```\n\n### 3. Configure RSS Sources\n\nEdit [`config/rss-sources.json`](config/rss-sources.json) to add your RSS feeds:\n\n```json\n{\n  \"sources\": [\n    {\n      \"name\": \"Green Tech News", "url\": \"https://example.com/green-tech/rss", "country\": \"us", "category\": \"renewable-energy"], ["Environment variables configured\n- [ ] OpenAI API key set\n- [ ] RSS sources configured\n- [ ] SSL certificates ready (if using HTTPS)\n- [ ] Domain name configured\n- [ ] Firewall rules set\n- [ ] Backup strategy in place\n- [ ] Monitoring configured\n\n### SSL/TLS Configuration\n\nFor production, use SSL/TLS certificates. Update [`docker/nginx.conf`](docker/nginx.conf):\n\n```nginx\nserver {\n    listen 443 ssl http2;\n    server_name yourdomain.com;\n\n    ssl_certificate /etc/nginx/ssl/fullchain.pem;\n    ssl_certificate_key /etc/nginx/ssl/privkey.pem;\n\n    # SSL configuration\n    ssl_protocols TLSv1.2 TLSv1.3;\n    ssl_ciphers HIGH:!aNULL:!MD5;\n    ssl_prefer_server_ciphers on;\n\n    # ... rest of configuration\n}\n\nserver {\n    listen 80;\n    server_name yourdomain.com;\n    return 301 https://$server_name$request_uri;\n}\n```\n\nMount certificates in [`docker-compose.yml`](docker-compose.yml):\n\n```yaml\nproxy:\n  volumes:\n    - ./docker/nginx.conf:/etc/nginx/nginx.conf:ro\n    - ./certs/fullchain.pem:/etc/nginx/ssl/fullchain.pem:ro\n    - ./certs/privkey.pem:/etc/nginx/ssl/privkey.pem:ro\n```\n\n### Using Let's Encrypt\n\n1. **Install Certbot**\n\n```bash\nsudo apt-get update\nsudo apt-get install certbot\n```\n\n2. **Generate $BACKUP_DIR\n\ndocker-compose exec -T db cat /app/data/greennews.db > $BACKUP_DIR/greennews_$DATE.db\n\n# Keep only last 7 days\nfind $BACKUP_DIR -name \"greennews_*.db\" -mtime +7 -delete\n```\n\nRun backups with cron:\n\n```bash\n# Add to crontab\n0 2 * * * /path/to/greennewstracker/scripts/backup.sh\n```\n\n### Database Restore\n\n```bash\n#!/bin/bash\n#
